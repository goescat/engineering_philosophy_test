# 軟體架構 21 問

一個單一 HTML 檔案的工程哲學測驗小遊戲：回答 21 題「二選一」的架構／工程
價值觀問題，最後得出 8 種工程哲學角色之一。

## 這裡直接玩
https://goescat.github.io/engineering_philosophy_test/

## 專案結構

```
engineering_philosophy_test/
├── index.html   # 網站本體（HTML + CSS + JS + 8 張人物圖片 base64，全部塞在一起）
└── README.md
```

`index.html` 內部大致分三塊：
- `<style>`：版面、深色主題、像素飄落背景動畫的樣式
- 內嵌 `<script>` 開頭的 `profileImages`：8 張人物圖的 base64 資料
- 主要邏輯：`questions` / `weightMap` / `profiles` / `getProfile()` 等函式

## 測驗流程

1. 開場畫面按「開始測驗」才會進入第一題（`startQuiz()`）。
2. 21 題全部是二選一，每題只會影響「一個」分數軸（見下）。
3. 答完自動跳出結果頁：對應角色、8 軸長條圖、4 項角色特質。
4. 「再測一次」會回到開場畫面，不會直接跳回第一題。

## 8 個分數軸

每題屬於下面 8 軸中的其中 1 軸，答 A / B 會讓該軸往其中一端加分：

| 軸 | 兩端 | 題數 |
|---|---|---|
| 架構觀 | 秩序 ↔ 彈性 | 3 |
| 開發觀 | 設計 ↔ 實用 | 3 |
| 工程觀 | 品質 ↔ 效率 | 3 |
| 時間觀 | 長期 ↔ 當下 | 3 |
| 決策觀 | 數據 ↔ 直覺 | 3 |
| 商業觀 | 可靠性 ↔ 經濟性 | 3 |
| 變化觀 | 演化 ↔ 革命 | 2 |
| 組織觀 | 個人專業 ↔ 團隊韌性 | 1 |

結果頁的 8 條長條圖都會顯示，但**只有架構觀×開發觀×商業觀**這 3 軸會拿來決定
最終角色，其餘 5 軸純粹是額外的個人特質參考、不影響選到哪個角色。這 3 個
決定用的軸都由 3 題（單數）組成，兩邊不會打平，讓 8 種角色的出現機率盡量
平均（實測隨機模擬 50 萬次，8 種角色都落在 12.4%～12.65%，接近理論值
12.5%）。

## 8 種角色判定表

架構觀 × 開發觀 × 商業觀 剛好 2×2×2 = 8 種組合，一組對一個角色：

| 架構觀 | 開發觀 | 商業觀 | 角色 |
|---|---|---|---|
| 秩序 | 設計 | 可靠 | 帝國建築師 |
| 彈性 | 設計 | 可靠 | 演化架構師 |
| 彈性 | 實用 | 經濟 | 極簡主義者 |
| 秩序 | 實用 | 經濟 | 務實征服家 |
| 秩序 | 設計 | 經濟 | 架構煉金術師 |
| 彈性 | 設計 | 經濟 | 產品戰略家 |
| 秩序 | 實用 | 可靠 | 堡壘守護者 |
| 彈性 | 實用 | 可靠 | 漸進設計師 |

判定邏輯在 `getProfile()`，程式碼本身就是上表的翻譯。

## 功能特色

- **像素飄落背景**：`#bgCanvas` 用 Canvas 畫小方塊緩速飄落，呼應人物插圖的
  像素風格；支援 `prefers-reduced-motion`（偏好減少動態效果時只畫靜態畫面）。
- **雙欄長條圖**：結果頁 8 軸長條圖不論手機或電腦都固定 2 欄並排，圖片
  不會拉太長。
- **儲存圖片**：把整個結果卡片（人物圖＋角色＋長條圖＋特質）存成一張
  `engineering_philosophy_test_result.png`：
  - 電腦版：直接觸發下載。
  - 手機版：因為手機瀏覽器對 `<a download>` 支援不穩定，改成把圖片顯示在
    全螢幕浮層裡，提示「長按圖片即可儲存到相簿」，用瀏覽器內建手勢存檔，
    最不容易出錯。iPad（會偽裝成 Mac 的 UA）也有特別偵測。
